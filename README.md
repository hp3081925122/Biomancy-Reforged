# Biomancy Reforged

Unofficial port of [Biomancy](https://github.com/Elenterius/Biomancy) 2.9.11 by Elenterius and RhinoW to Minecraft 1.21.1 NeoForge. Not affiliated with or endorsed by the original authors.

- CurseForge: https://www.curseforge.com/minecraft/mc-mods/biomancy-reforged
- Original project: [CurseForge](https://www.curseforge.com/minecraft/mc-mods/biomancy) · [Modrinth](https://modrinth.com/mod/biomancy) · [GitHub](https://github.com/Elenterius/Biomancy)

## Building

Requires Java 21.

```
./gradlew build
```

The release jar is `build/libs/biomancy-<version>-all.jar` (it bundles the H2 database via jarJar).

## Credits

All design, code, textures, models, sounds and music come from the original Biomancy by Elenterius, RhinoW and the Biomancy community contributors (see `CREDITS.md`). This port only updates the code to 1.21.1 NeoForge.
